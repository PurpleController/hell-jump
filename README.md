# Hell Jump

Play as a simple cube trying to jump, dodge, and survive your way out. Expect precise controls, increasing difficulty, and a whole lot of rage-quits (in the best way).

Made with love (and probably a bit of frustration) in the Czech Republic ❤️.

## About the Game

In **Hell Jump** you control a red cube trying to get out of Hell. Because the orange cube was bad but the red cube was good, Hell accidentally took you instead of the orange cube.

- **Genre:** Hardcore 2D platformer / rage game
- **Engine:** Godot
